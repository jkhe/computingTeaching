Learning Objective

Core Idea

What is Data?

Data is simply information we collect to help us understand the world, answer questions, or solve problems.

Type 1

WORDS

Qualitative Data

Information that describes things using descriptive words, qualities, labels, or categories.

Examples: Blue, Sunny, Quiet, LN14 KHE
Type 2

NUMBERS

Quantitative Data

Information that can be measured or counted using numerical values.

Examples: 15 Steps, 18.2 Degrees, 5 Seats

Help Desk

Stuck on your task? Use these guides:

The Golden Rule

Ask yourself: "Can I add these values together or calculate an average?"

  • If YES = It is Quantitative (Numbers).
  • If NO = It is Qualitative (Words/Labels).
